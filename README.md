_How do you use it?_
--------------------------------
don't worry, its very easy. <br>
Shrongebot uses something called _slash commands_. In fact almost every bot in slack uses this type of command. all you have to do in order to use shrongebot is to simply type in one of the 4 commands for the bot: <br>
<br>
  _/shrongebot-ping_ (want to identify latency? This is the one!) <br>
  <br>
  _/shrongebot-catfact_ (Larning something new about cats... cause why not) <br>
  <br>
  _/shrongebot-joke_ (Riddle me this!... ermm... i forgot :[ ) <br>
  <br>
  _/shrongebot-help_ (Can't remember the commands, just use this one!)
